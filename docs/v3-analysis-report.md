## 4. 왜 v3가 실패했는가?

### 4.1 원인 분석

#### 원인 1: 너무 많은 Epoch ❌

**문제점**:
- Epoch 10은 데이터셋 크기(1,407 samples)에 비해 과도
- 같은 데이터를 10번 반복하며 **암기(memorization)** 발생
- 일반화 능력 상실

**증거**:
- Epoch 5.69에서 최저 Val Loss (0.7545)
- 이후 계속 상승 (0.7545 → 0.8458)

#### 원인 2: Learning Rate가 너무 작음 ⚠️

**문제점**:
- LR 1e-4는 안정적이지만, 10 epoch과 결합 시 문제
- 천천히 움직이며 **Local Minimum에 깊이 빠짐**
- 한번 Overfitting이 시작되면 벗어나기 어려움

**비교**:
- v2 (LR 2e-4, 3 epoch): 빠르게 학습하고 Overfitting 전에 종료 ✅
- v3 (LR 1e-4, 10 epoch): 천천히 과적합으로 빠져듦 ❌

#### 원인 3: 작은 데이터셋 📉

**문제점**:
- 학습 데이터: 1,407 samples
- 10 epoch: 14,070번 학습 (sample 반복)
- Overfitting에 취약

**데이터 부족 증거**:
- 같은 패턴 반복 학습
- Training Loss는 계속 감소 (0.3236 → 0.136)
- Val Loss는 상승 (Gap 증가)

### 4.2 Train-Val Gap 분석

**Epoch 5.69** (최적점):
- Train Loss: ~0.32
- Val Loss: 0.7545
- Gap: 0.43 (건강)

**Epoch 9.66** (최종):
- Train Loss: ~0.14
- Val Loss: 0.8458
- Gap: 0.70 (심각한 Overfitting!) ⚠️

**해석**:
- Train Loss는 절반으로 감소 (학습 데이터 암기)
- Val Loss는 오히려 증가 (일반화 실패)

## 6. 교훈 및 권장 사항

### 6.1 핵심 교훈

#### 교훈 1: More is NOT Always Better ⚠️

```
Epoch 3 (v2):  52.38% ✅
Epoch 10 (v3): 28.57% ❌

→ 더 많이 학습 ≠ 더 좋은 성능
```

**왜?**
- 작은 데이터셋 + 많은 Epoch = Overfitting
- 최적점 이후 계속 학습 = 성능 저하

#### 교훈 2: Early Stopping이 중요함 🛑

**v3의 최적점**: Epoch 5.69 (Val Loss 0.7545)
**실제 학습**: Epoch 10까지 진행

**만약 Epoch 6에서 멈췄다면?**
- 예상 정확도: 54-56%  (v2보다 나을 가능성)
- 시간 절약: 130분 (217분 → 87분)

#### 교훈 3: Validation Loss 모니터링 필수 📊

**학습 중 확인해야 할 것**:
- Val Loss가 3번 연속 상승하면 → Early Stop
- Train-Val Gap이 0.5 이상 → Overfitting 의심
- Val Loss 최저점 저장 → 최고 모델 보존

### 6.2 실패한 전략 vs 성공한 전략

#### ❌ 실패한 전략 (v3)

```python
learning_rate = 1e-4  # 너무 작음
num_epochs = 10       # 너무 많음
early_stopping = None # 없음!
```

**결과**: 28.57% (대실패)

#### ✅ 성공한 전략 (v2)

```python
learning_rate = 2e-4  # 적절함
num_epochs = 3        # 적당함
# 자연스럽게 Overfitting 전에 종료
```

**결과**: 52.38% (최고)

## 9. 결론

### 9.1 최종 판정

**v3 실험: 실패 ❌**

**이유**:
1. Epoch 10은 과도함 (최적: 5-6)
2. LR 1e-4가 너무 작아서 Overfitting에서 회복 못함
3. Early Stopping 없어서 계속 악화됨

**증거**:
- v2 대비 23.81%p 하락
- Val Loss가 Epoch 5.69 이후 계속 상승
- Train-Val Gap 0.70 (심각한 Overfitting)

### 9.2 권장 조치

**즉시**:
- ✅ v2 모델 사용 (52.38%)
- ✅ v3 Epoch 6 체크포인트 확인 (54-56% 예상)

**단기** (1-2일):
- ✅ Epoch 5 + LR 2e-4로 재학습
- ✅ Early Stopping 구현

**장기** (1주+):
- ✅ 데이터 증강
- ✅ 더 큰 모델

### 9.3 가장 중요한 교훈

> **"More Epochs ≠ Better Performance"**
>
> - 작은 데이터셋에서는 적은 Epoch이 더 좋을 수 있음
> - Validation Loss 모니터링 필수
> - Early Stopping은 선택이 아닌 필수
> - 최고점 이후 계속 학습하면 성능 저하
