## 3. 결정론적 모델 (Deterministic Model) 확인

### 3.1 결정론적이란?

> **결정론적 모델**: 동일한 입력에 대해 항상 동일한 출력을 생성하는 모델

```python
# 결정론적 모델 동작
input: "고구려의 수도는?"
output: "2. 국내성" (항상 동일)

# 비결정론적 모델 동작
input: "고구려의 수도는?"
output 1: "2. 국내성" (확률적)
output 2: "2. 국내성" (90% 확률)
output 3: "1. 평양" (10% 확률)
```

### 3.2 v2 모델의 결정론적 설정

```python
# evaluate_v2_retest.py:73
outputs = model.generate(
    **inputs,
    max_new_tokens=512,
    do_sample=False  # ← 결정론적 생성
)
```

**설정 분석**:
- `do_sample=False`: 탐욕적 디코딩 (greedy decoding) 사용
- 항상 가장 확률이 높은 토큰만 선택
- temperature, top_p, top_k 파라미터 무시
