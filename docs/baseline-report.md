## Key Findings and Recommendations

### 1. Answer Extraction System Issues

**Critical Problem**: 답변 추출 로직(`extract_answer()`)이 매우 불안정합니다.

**Evidence**:
- Sample 1, 4, 10: 모델이 명시적으로 다른 번호를 선택했으나 extraction 로직이 다른 답을 추출 (False Positive)
- Sample 5, 6: 모델이 정확한 답을 선택했으나 extraction 로직이 잘못된 답을 추출 (False Negative)

**Impact**: 실제 정확도 14.29%는 **신뢰할 수 없는** 수치입니다. True accuracy는 더 낮거나 높을 수 있습니다.

**Recommendation**:
- 번호 기반 명확한 추출 로직 구현 (e.g., "정답은 3번입니다" 형식 강제)
- 또는 LLM을 사용한 answer verification 단계 추가

### 2. Token Limit Issues

**Problem**: `max_new_tokens=100` 제약이 너무 작습니다.

**Evidence**:
- Sample 2, 3, 8, 9: 응답이 중간에 잘려 추론이 미완성
- 평균적으로 설명을 시작하다가 "따라서...", "이는..." 등에서 끝남

**Recommendation**:
- `max_new_tokens`를 최소 200~300으로 증가
- 또는 응답 형식을 "번호만 출력"으로 단순화

### 3. Historical Knowledge Gaps

**Problem**: 모델이 한국사 세부 지식에서 부족함을 보입니다.

**Evidence**:
- Sample 7: 홍대용을 김정호로 잘못 식별
- Sample 4: 세종대와 영조-정조 시대 혼동

**Recommendation**:
- Fine-tuning 시 한국사 인물, 시대별 사건 연결 강화 필요
- 특히 시대 구분(고려, 조선 전/중/후기) 학습 강화

### 4. Model Strengths

**Positive Observations**:
- Sample 5, 6: 명확한 추론과 설명 제시 능력 보유
- 역사적 맥락 이해 시도 (Sample 2, 3)
- 부분적으로 정확한 역사 지식 보유

**Recommendation**:
- Fine-tuning 시 설명 능력 유지하면서 factual accuracy 개선
- Chain-of-thought prompting 활용 고려

## Conclusion

Korean History 평가 결과 14.29% 정확도는 매우 낮지만, **평가 시스템의 기술적 한계**가 결과에 큰 영향을 미쳤습니다. Answer extraction 로직의 불안정성과 token 제약이 모델의 실제 능력을 정확히 측정하지 못하게 했습니다.

**Next Steps**:
1. Answer extraction 로직 개선
2. Token limit 증가 또는 응답 형식 단순화
3. 재평가 후 fine-tuning 전략 수립
4. 한국사 전문 데이터셋 추가 활용 고려
